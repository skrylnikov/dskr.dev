# Локальная админка

```sh
pnpm install
pnpm admin:dev
```

Откройте [http://127.0.0.1:4322](http://127.0.0.1:4322). Команда запускает интерфейс Mantine, файловый API на порту 4323 и Astro preview на 4324. Занятый порт считается ошибкой; Ctrl+C останавливает все три сервера. Админка не входит в production-сборку сайта.

## Редактирование

Разделы «Блог» и «Путешествия» читают текущие MDX/Markdown-файлы из `src/content`. Выберите язык RU/EN, найдите материал либо создайте новый. Для главы или заметки откройте поездку и нажмите «Добавить главу / заметку». Перевод создаётся отдельным материалом на другом языке с тем же slug. Сначала должна существовать поездка на языке создаваемой записи.

Редактор поддерживает обычное форматирование, ссылки, изображения, списки, таблицы, код с языком, раскрывающиеся блоки и галереи. Для редактирования изображения выделите его и нажмите «Изображение». Выравнивание таблицы применяется ко всему столбцу; объединённые ячейки и многострочные ячейки не поддерживаются Markdown-форматом. Галерею можно выбрать, переместить или убрать из текста. Кнопка «Редактировать медиа» в её блоке открывает состав, порядок и подписи в модальном окне, сохраняя несохранённый текст и позицию курсора. Тот же редактор доступен в разделе «Медиа».

Для поездок и глав выберите 3–8 фотографий коллажа. Если выбран один или два кадра, редактор повторит их до трёх, как существующий импорт путешествий. Порядок записей уникален внутри поездки и языка. При изменении порядка сначала назначьте свободное значение, чтобы избежать конфликта с другой записью.

«Сохранить» записывает рабочий файл без Git-операций. Правка только метаданных сохраняет исходное тело MDX. Изменённый вне админки файл нельзя перезаписать старой версией: откройте его заново. Неизвестный JSX или выражения доступны только для чтения; исходный файл остаётся нетронутым. Удаление файлов и изменение slug существующих материалов выполняются вручную.

«Сохранить и открыть превью» сохраняет валидный материал, перезапускает Astro для обновления манифестов и открывает настоящую страницу сайта. В локальном превью видны черновики путешествий, включая главы и заметки внутри черновика поездки. Новые статьи блога получают `hidden: true`: это исключает их из ленты и RSS, но **не скрывает страницу по прямому URL** после production-сборки.

## Медиа

Нужны `ffmpeg`, `ffprobe`, `cjxl` и `djxl`; на macOS: `brew install ffmpeg jpeg-xl`. Сервер использует существующий обработчик медиа, рецепты JPEG/WebP/JXL и MP4, а также текущие S3-переменные из игнорируемого `.env`, приведённые в `.env.media.example`. Ключи не передаются браузеру.

В разделе «Медиа» выберите галерею или укажите ID новой и добавьте файлы. Лимиты одного запроса: 100 файлов, до 1 ГиБ каждый. После обработки они доступны локально. Входы, оригиналы, очередь загрузки и производные сохраняются в `.state`; не удаляйте её до успешной отправки в S3. Редактирование текста и старых подписей не требует S3 или исходных фото.

Галереи общие для RU/EN. Можно менять alt/подписи обоих языков, порядок и состав. Фотографию, используемую в обложке или коллаже, сначала нужно убрать из этих ссылок. Удаление элемента галереи не удаляет объекты из S3.

Кнопка «Загрузить в S3» отправляет новые подготовленные вложения в существующие bucket и проверяет размеры. Ошибка сохраняет очередь для повтора, в том числе после перезапуска админки. Производные становятся доступны по публичному URL **до коммита**; `draft` не закрывает доступ к медиа. Готовые опубликованные вложения не требуют повторной обработки или старых оригиналов.

Последовательность работы: отредактировать → сохранить → проверить превью → загрузить новые медиа в S3 → проверить `git diff` → вручную commit/push. До загрузки производные берутся локально, остальные медиа — через публичный медиашлюз. Оригиналы через админку не раздаются.

## Проверки

```sh
pnpm admin:check
pnpm admin:test
pnpm admin:build
pnpm admin:e2e
pnpm test
pnpm travel:e2e
```

Browser-тесты используют Chromium из Playwright и тестовый контент в `.state/admin-e2e`, не рабочие материалы. Установка браузера: `pnpm exec playwright install chromium`. Автоматические проверки не отправляют данные в настоящий S3. API-тесты подменяют S3 и проверяют конфликт записи, ссылки, обход путей и сохранность MDX.

Для изолированных проверок предусмотрены `ADMIN_CONTENT_ROOT` и `ADMIN_STATE_ROOT`; обычный запуск использует `src/content` и `.state/admin`. Производные продолжают храниться в общей `.state/travel` для совместимости с CLI. Админка предназначена только для доверенной локальной машины и слушает `127.0.0.1`; публикация через reverse proxy не предусмотрена.
